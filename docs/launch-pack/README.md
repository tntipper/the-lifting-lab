- [HARNESS-SPEC.md](HARNESS-SPEC.md): the planned supplier feed, stock, ordering and tracking system.
- [TASK-QUEUE.md](TASK-QUEUE.md): ticket scope, order, acceptance checks and branch instructions.
- [HOW-TO-RUN-CODEX.md](HOW-TO-RUN-CODEX.md): plain-English workflow and prompt examples.

Follow the [root AGENTS.md](../../AGENTS.md) for project instructions; [CLAUDE.md](../../CLAUDE.md) imports it too. Read the top of [.agent/HANDOVER.md](../../.agent/HANDOVER.md) for the latest work note. The [signed-off T01 reconciliation](../ops/2026-10-reconcile.md) records decisions; the [completion tracker](../ops/completion-tracker.md) and older plans retain supporting historical evidence. Current launch scope is governed by this pack.

Keep these four launch documents here only. Update links when changing their names or locations; do not create copies under `docs/` or elsewhere.
