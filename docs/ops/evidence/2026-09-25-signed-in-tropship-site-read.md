# Signed-in Tropicana site read — account pages and one product

Read-only Safari inspection on 25 September 2026 using the owner's existing sign-in. No basket item, order, payment, API request or account setting changed. These are dated observations of the rendered website, not a current account contract or proof that every SKU uses the same rules.

## Information already available on the website

- The signed-in [TropShip Docs page](https://www.tropicanawholesale.com/my-account/tropship-docs/) contains the order API specification and Swagger link. It says one order per request; unavailable/non-dropship products or unsupported delivery countries are rejected; only the UK is presently available for dropshipping. Its `validate_only=true` option validates an order without submitting or charging it. Live orders charge the saved card, and bearer tokens last five minutes. The specification can be read without creating a credential. No API action was performed.
- A signed-in search for `APP449` led to the [Applied Nutrition Creatine Monohydrate listing](https://www.tropicanawholesale.com/shop-by-brand/Applied-Nutrition/Applied-Nutrition-Creatine-Monohydrate/). The 250g unflavoured row displayed SKU `APP449`, barcode `5056555206218` on its barcode tab, nutrition/ingredient text on a separate tab, best-before 31 August 2028, and 143 units in stock at the observation time. The price toggle showed **£7.45 + VAT** versus **£8.94 including VAT**. The supplied 14 September feed had `ProductPrice=7.45`, so this SKU supports interpreting that feed value as ex VAT, not inclusive. It does **not** by itself prove the basis for every feed SKU or the final invoiced cost. The product page contains broad efficacy copy; do not copy it into TLL claims without independent review. Its nutrition and barcode are supplier-site assertions, not proof of a current manufacturer-approved label revision.
- The signed-in [Delivery page](https://www.tropicanawholesale.com/help/delivery/) displays £5+VAT below £100 and free delivery above £100, weekday 4pm cut-off, possible delays and possible charges on declined deliveries. This is the generic page; the separate account welcome email says the £100 threshold belongs to the wholesale account and £5+VAT applies to **each TropShip order**. The account-specific ambiguity therefore remains and the conservative £6-per-TropShip-order planning allowance stays in force.
- The [Returns page](https://www.tropicanawholesale.com/help/returns/) describes submitting a return from order history, a 14-day supplier return window for some goods, and prompt reports/photos for damage, incorrect or missing goods. It does not clearly separate TropShip from wholesale. These are supplier-to-TLL procedures, not a replacement for TLL's obligations to its own retail customers.

## Result for the supplier email

Remove requests for a general API specification, ordinary product-page barcode/nutrition availability and generic delivery/returns rules because those are visible. Ask for the **remaining account-specific facts**: whether TropShip orders always incur £5+VAT and any surcharges; whether the feed's price/tax/pack interpretation holds for all products; whether an exact manufacturer-backed label/source and image-use rights are available; whether genuine RRP exists; feed timing and order-time stock checks; duplicate-safe API submission and TropShip-specific cancellation/returns/credits. No supplier email has been sent.
